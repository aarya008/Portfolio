# Aary Tagare Portfolio

A single-page portfolio with a FastAPI + Gemini chatbot named Karma.

## Architecture

- Frontend: `public/index.html`
- Chat request: `POST /api/chat`
- Health check: `GET /api/health`
- Backend entrypoint: `server.py`
- Knowledge source: `Aary_Tagare_Complete_Profile.md`
- Private configuration: `GEMINI_API_KEY` environment variable

See `VERCEL_DEPLOYMENT.md` for complete deployment and verification steps.
